## 🔄 Процесс работы

### 1️⃣ Создание сервера

```
Пользователь         Frontend           Backend          Сервер
    │                   │                  │               │
    │ Нажимает          │                  │               │
    │ "Создать"         │                  │               │
    ├──────────────────>│                  │               │
    │                   │ POST /api/servers│               │
    │                   ├─────────────────>│               │
    │                   │                  │ Создаёт       │
    │                   │                  │ конфигурацию  │
    │                   │ ✅ Success       │               │
    │                   │<─────────────────┤               │
    │ Показывает новый  │                  │               │
    │ сервер в списке   │                  │               │
    │<──────────────────┤                  │               │
```

## 🔐 Безопасность

```
┌────────────────────────────────────────────────────────┐
│              Защитные механизмы                        │
└────────────────────────────────────────────────────────┘

1. Аутентификация
   ┌──────────┐
   │  Login   │
   └────┬─────┘
        │
        ↓
   ┌─────────────┐      ┌──────────────┐
   │ bcrypt hash │ ───> │  JWT token   │
   │  password   │      │ (24h expiry) │
   └─────────────┘      └──────────────┘
                              │
                              ↓
                        Все API запросы
                        с токеном

2. Изоляция процессов
   Каждый сервер = отдельный subprocess
   Свой stdin/stdout/stderr
   Свой рабочий каталог

3. Валидация
   - Проверка путей (не выше /home)
   - Проверка команд (нет sudo)
   - Проверка прав доступа
```

## 🚀 Производительность

```
Ресурсы Backend:
├─ CPU: ~5% (idle), ~15% (active)
├─ RAM: ~50MB (idle), ~100MB (active)
└─ Диск: ~10MB (база + логи)

Каждый сервер:
├─ Зависит от приложения
├─ Мониторинг в реальном времени
└─ Никакого overhead от панели

WebSocket:
├─ Обновления каждые 2 сек
├─ Только изменённые данные
└─ Автоматический reconnect
```
